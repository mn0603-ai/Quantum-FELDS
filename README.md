# Quantum-FELDS

Quantum Free-Energy-Landscape-Derived Spectroscopy (Quantum FELDS)

A computational framework that transforms collective free-energy coordinates obtained from molecular-dynamics simulations into quantum-mechanical state representations.

Workflow

P(q)
→ F(q)
→ Q
→ M_eff
→ Hamiltonian
→ wavefunctions
→ quantum probability densities

Current application:
Liquid water hydrogen-bond-network collective coordinates.
